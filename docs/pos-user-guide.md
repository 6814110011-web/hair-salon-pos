# คู่มือใช้งาน Hair Salon POS

## เริ่มระบบและบัญชีผู้ดูแล

รัน `php artisan migrate` แล้ว `php artisan serve` เปิด http://127.0.0.1:8000
สร้างหรือกำหนดผู้ดูแลด้วย `php artisan salon:admin` ระบุอีเมลที่ต้องการ ถ้าเป็นบัญชีเดิม
ยืนยันการเปลี่ยนสิทธิ์โดยรหัสผ่านเดิมยังใช้ได้ ถ้าเป็นบัญชีใหม่ให้ตั้งชื่อและรหัสผ่านในเทอร์มินัล
ไม่เปิดสมัครพนักงานสาธารณะ ผู้ดูแลเพิ่มพนักงานจากเมนูพนักงาน

## ลูกค้า

เลือก **ลูกค้า → เพิ่มลูกค้า** กรอกชื่อและเบอร์โทรไม่ซ้ำ บันทึกแล้วเปิดดูประวัติได้
จำนวนครั้งและวันที่ใช้บริการล่าสุดอัปเดตเมื่อบิลชำระสำเร็จ ไม่ต้องกรอกเอง

## พนักงาน

ผู้ดูแลเลือก **พนักงาน → เพิ่มพนักงาน** กรอกชื่อ อีเมล บทบาท และรหัสผ่านเริ่มต้น
บทบาทผู้ดูแลจัดการร้านได้ แคชเชียร์ขายและจัดการลูกค้าได้ ช่างดูบริการและงานที่รับผิดชอบ
แก้พนักงานโดยเว้นช่องรหัสผ่านว่างเพื่อใช้รหัสเดิม ปิดใช้งานแทนลบเพื่อรักษาประวัติ
ระบบไม่อนุญาตให้ปิดหรือลดสิทธิ์ผู้ดูแลที่เปิดใช้งานคนสุดท้าย

## สินค้าและสต็อก

เลือก **สินค้า / สต็อก → เพิ่มสินค้า** กรอกรหัส ชื่อ ต้นทุน ราคาขาย หน่วย และจุดเตือน
สินค้าใหม่มีจำนวน 0 เปิดรายละเอียดสินค้าและใช้ **รับสินค้าเข้า** เพื่อเพิ่มจำนวนพร้อมเหตุผล
ถ้าตรวจนับแล้วจำนวนจริงต่างจากระบบ ใช้ **ปรับยอดหลังตรวจนับ** และกรอกยอดคงเหลือใหม่
ทุกการรับเข้า ขาย คืนสต็อก และปรับยอดมีประวัติ ยกเลิกการขายใช้การยกเลิกบิล ไม่ปรับสต็อกซ้ำเอง
แคชเชียร์ดูราคาขาย/คงเหลือได้ ไม่เห็นต้นทุนหรือแก้สต็อก

## บริการ

ผู้ดูแลเลือก **บริการ → เพิ่มบริการ** ระบุประเภท ราคา และเวลาที่ใช้
ปิดบริการที่เลิกใช้แทนการลบ บิลเก่าจะยังคงชื่อและราคาขณะขาย

## ขายและใบเสร็จ

1. เลือก **ขาย / ใบเสร็จ → เปิดบิลขาย**
2. ค้นหาและกดสินค้า/บริการเพื่อเพิ่มตะกร้า ปรับจำนวนหรือกดลบได้
3. เลือกช่างให้แต่ละรายการบริการ ต้องมีพนักงานบทบาทช่างที่เปิดใช้งานก่อน
4. เลือกลูกค้าสมาชิกหรือใช้ลูกค้าทั่วไป สมาชิกได้รับการนับหนึ่งครั้งต่อบิลที่ชำระแล้ว
5. เลือกโปรโมชั่นจากข้อมูลที่มีอยู่ได้ ระบบตรวจจำนวนครั้งและสิทธิ์ซ้ำเมื่อยืนยัน
   ยังไม่มีหน้าจัดการโปรโมชั่นหรือกติกาแต้มใหม่ในการพัฒนารอบนี้
6. เลือกเงินสดและกรอกเงินรับ หรือเลือกพร้อมเพย์/โอน/บัตรพร้อมเลขอ้างอิงหลังตรวจการรับเงินจริง
7. ตรวจยอดและกด **ยืนยันชำระเงิน** ระบบบันทึกบิล ตัดสต็อก และอัปเดตลูกค้าพร้อมกัน
8. กด **พิมพ์ใบเสร็จ** เพื่อเปิดหน้าต่างพิมพ์ของเบราว์เซอร์

เมื่อราคาหรือสถานะสินค้าเปลี่ยน ระบบให้ตรวจรายการอีกครั้ง ไม่ใช้ยอดจากหน้าจออย่างเดียว
ถ้าแจ้งว่าชำระซ้ำจากบิลเดียวกัน ระบบจะเปิดใบเสร็จเดิมโดยไม่ขายซ้ำ
การรีเฟรชแบบ GET ที่หน้าเปิดบิลใหม่เป็นการเริ่มบิลใหม่โดยตั้งใจ

## ยกเลิกและคืนเงิน

ผู้ดูแลเปิดบิล ระบุเหตุผลไม่เกิน 200 ตัวอักษร แล้วกด **ยกเลิกบิล**
ระบบคืนสต็อกและสิทธิ์ที่บันทึกไว้ตามเงื่อนไข บิลที่รับเงินแล้วจะแสดง **รอคืนเงิน**
หลังคืนเงินจริงให้ลูกค้า ให้กรอกหลักฐานหรือเลขอ้างอิง แล้วกด **บันทึกว่าคืนเงินจริงแล้ว**
ปุ่มนี้เก็บหลักฐานเท่านั้น ไม่โอนเงินหรือเชื่อมธนาคาร การยืนยันซ้ำไม่เปลี่ยนหลักฐานเดิม
ถ้าแต้มจากบิลเก่าถูกใช้ไปแล้ว หรือประวัติสต็อกไม่ตรงบิล ระบบจะไม่ยกเลิกจนกว่าจะตรวจสอบ

## Dashboard และรายงาน

Dashboard แสดงภาพรวมตามสิทธิ์ ผู้ดูแลเห็นทั้งร้าน แคชเชียร์เห็นยอดของตน ช่างเห็นงานของตน
ผู้ดูแลเลือก **รายงาน** กรองวันที่เพื่อดูยอดสุทธิ ส่วนลด จำนวนบิล ยอดเฉลี่ย และวิธีรับเงิน
ยอดแยกสินค้า/บริการเป็นยอดก่อนส่วนลดระดับบิล บิลยกเลิกไม่รวมในยอดขายสุทธิ
ยอดรอคืนเงินและจำนวนบิลยกเลิกอิงวันที่ยกเลิกตามเวลาไทย แยกจากยอดขาย

## ข้อมูลตัวอย่างและการแก้หน้าตา

ถ้าต้องการข้อมูลตัวอย่าง รัน `php artisan db:seed --class=SalonDemoSeeder` ด้วยตนเอง
คำสั่งเพิ่มลูกค้า สินค้า และบริการตัวอย่างเท่านั้น ไม่สร้างบัญชีหรือบิลและไม่เติมสต็อกอัตโนมัติ
แก้หน้าจอใน `resources/views/` แก้ CSS ใน `public/css/app.css` และตะกร้าใน `public/js/pos.js`
ไม่ต้องรัน npm ทุกฟอร์มเปลี่ยนข้อมูลต้องรักษา CSRF และ escape ข้อมูลที่แสดงด้วย `e()`
