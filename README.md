# Hair Salon POS

ระบบ POS ร้านทำผม ใช้ Laravel 12 และ PHP 8.2 ขึ้นไป พร้อมหน้าลูกค้า พนักงาน สินค้า/สต็อก บริการ ขาย ใบเสร็จ รายงาน และ Dashboard

## โครงสร้างหน้าจอ

- `resources/views/` — HTML ผสม PHP ในไฟล์ `.php`
- `resources/views/layouts/header.php` และ `footer.php` — ส่วนหัว เมนู และส่วนท้ายร่วมกัน
- `resources/views/partials/messages.php` — ข้อความแจ้งผลและข้อผิดพลาดของฟอร์ม
- `public/css/app.css` — CSS ธรรมดา
- `public/js/app.js` — JavaScript ธรรมดา สำหรับยืนยันก่อนปิดใช้งานบัญชี

ไม่ต้องติดตั้ง Node.js หรือรัน npm เพื่อใช้งานหน้าจอ แก้ CSS/JavaScript แล้วรีเฟรชหน้าได้เลย
โปรเจกต์ไม่ใช้ Blade, Tailwind CSS, Alpine.js หรือ Vite ในหน้าจอของแอป
ตัว Laravel ยังมี Blade เป็นส่วนหนึ่งของ framework ตามปกติ ไม่ต้องแก้ไฟล์ใน vendor

## เริ่มใช้งาน

1. รัน `composer install`
2. หากยังไม่มี `.env` ให้คัดลอก `.env.example` เป็น `.env` และรัน `php artisan key:generate`
3. ตั้งค่าฐานข้อมูลใน `.env` แล้วรัน `php artisan migrate`
4. รัน `php artisan serve` หรือ `composer run dev`
5. เปิด http://127.0.0.1:8000

สร้างหรือกำหนดผู้ดูแลเริ่มต้นด้วย `php artisan salon:admin` แล้วเข้าสู่ระบบด้วยอีเมลที่กำหนด
บัญชีเดิมที่เปลี่ยนเป็น admin ใช้รหัสผ่านเดิม ไม่เปิดสมัครพนักงานจากหน้าเว็บสาธารณะ
ผู้ดูแลเพิ่มพนักงานได้จากเมนูพนักงาน

ระบบอีเมลรีเซ็ตรหัสผ่านและยืนยันอีเมลต้องตั้งค่า MAIL ใน `.env`
หากใช้ queue สำหรับงานอื่น ให้เปิดเทอร์มินัลแยกแล้วรัน `php artisan queue:listen`

## การเขียนหน้าจอ

Controller ใช้ `return view('ชื่อหน้า', ['ข้อมูล' => $value]);` ได้เหมือนเดิม
ไฟล์หน้าจอใช้ `require` เพื่อรวมส่วนหัวและส่วนท้าย
แสดงข้อมูลด้วย `<?= e($value) ?>` เพื่อป้องกัน HTML ที่ไม่ต้องการ
ฟอร์มที่ส่งข้อมูลต้องใส่ `<?= csrf_field() ?>`
ฟอร์ม PATCH, PUT, DELETE ต้องเพิ่ม `<?= method_field('patch') ?>` ตาม HTTP method

## ทดสอบ

รัน `php artisan test` ใช้ SQLite ในหน่วยความจำ ไม่ใช้ฐานข้อมูลจริง
ชุดทดสอบกำหนด Faker เป็น en_US เพื่อให้สร้างอีเมลได้โดยไม่ต้องพึ่ง PHP intl สำหรับชื่อภาษาไทย

## สถานะ

มีหน้าหลัก Dashboard เข้าสู่ระบบ ออกจากระบบ ลืม/ตั้งรหัสผ่าน
ยืนยันรหัสผ่าน ยืนยันอีเมล แก้ไขโปรไฟล์ เปลี่ยนรหัสผ่าน และปิดใช้งานบัญชี
มีหน้าจัดการลูกค้า พนักงาน สินค้า สต็อก บริการ ขาย รับชำระเงิน ใบเสร็จ ยกเลิก/คืนเงิน และรายงานแล้ว
อ่าน [คู่มือใช้งาน](docs/pos-user-guide.md) สำหรับขั้นตอนทุกโมดูล
ข้อมูลตัวอย่างเพิ่มได้เมื่อเลือกเรียก `php artisan db:seed --class=SalonDemoSeeder` เท่านั้น
กติกาแต้มใหม่และหน้าจัดการโปรโมชั่นยังไม่อยู่ในรอบนี้ ใช้โปรโมชั่นจากข้อมูลเดิมในหน้าขายได้

## การปรับฐานข้อมูล POS

เปลี่ยน `users.is_activate` เป็น `is_active` ผ่าน migration โดยคงค่าเดิม
การปิดบัญชีจะเก็บประวัติพนักงานและบิลไว้ พร้อมป้องกันการเข้าสู่ระบบของบัญชีที่ปิดใช้งาน
เพิ่มประวัติใช้โปรโมชั่น รายการคืนสต็อก/แต้ม และรายการรอคืนเงินสำหรับการยกเลิกบิล
หน้าขาย ยกเลิกบิล และยืนยันการคืนเงินจริงเชื่อมกับ services แล้ว ระบบไม่ได้โอนเงินหรือเชื่อมธนาคาร
อ่านกติกาและวิธีเชื่อมต่อโมดูลขายใน [database/POS-NOTES.md](database/POS-NOTES.md)
